# Contributing

New skills and improvements welcome.

1. Each skill is a folder under `skills/` with a `SKILL.md` (frontmatter: name, description with triggers, version; then the instructions).
2. Keep skills focused, honest, and stack-aware; tailor to the repo, never paste generic boilerplate.
3. One clear `## Done when` check per skill.

Adding one good skill is a great first PR.
